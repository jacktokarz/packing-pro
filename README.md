# Travel Packing Assistant

A starter web app for helping people prepare packing lists for trips. This is intentionally a lightweight scaffold; the packing logic and product features will be added later.

## Stack
- Next.js App Router
- React
- TypeScript
- Plain CSS (no component library yet)

## Run locally
1. Install Node.js (current LTS recommended).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open http://localhost:3000.

## Starter structure
- `src/app/` — routes and global styling
- `src/components/` — reusable UI components
- `src/lib/` — shared types and future app logic

## Initial product areas
- Dashboard / trip overview
- Create-trip flow
- Packing list
- Preferences and reusable packing profiles

These are placeholders, not implemented workflows yet.
